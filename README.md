# Vogue Reader

**Vogue Reader** - это элегантное приложение для распознавания документов, вдохновленное версткой модных глянцевых журналов. 

Проект объединяет современные нейросети (EasyOCR) и минималистичный дизайн. Идеально подходит для оцифровки VIP-досье, паспортов и договоров в премиальных отелях.

## Возможности

- Верстка результата в стиле журнальной статьи (с буквицей и выравниванием по ширине).
- Загрузка изображений (JPG, JPEG, PNG).
- Автоматическое сохранение в текстовый файл.
- Извлечение русского и английского текста.

## Требования

- Python 3.9+
- pip

## Установка

**1. Клонирование:**
```bash
git clone <адрес_репозитория>
cd <имя_репозитория>
```
Для Windows:

python -m venv .venv
.venv\Scripts\activate

Для Linux / macOS:

python3 -m venv .venv
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt

streamlit run app.py

##Принцип работы

Пользователь загружает фотографию документа.

Левая колонка отображает «портрет» (сканированное изображение).

Нейросеть EasyOCR распознает текст.

Первая строка выводится как крупный заголовок, остальной текст — как журнальная статья с буквицей.

Результат сохраняется в файл vogue_dossier_<имя_файла>.txt.
